About the Project
-----------------
FUTUREX is a simple AI-powered chatbot built using Python, LangChain, and Groq API.

It helps users explore what might happen when they make different decisions. It provides possible positive and negative outcomes to help users think before making decisions.

Technologies Used
-----------------
Python
LangChain
Groq API
Google Colab
Llama Prompt Guard

Features
--------
Understands user decisions and questions.
Suggests possible future outcomes.
Shows both positive and negative consequences.
Provides up to 4 possible outcomes.
Uses simple and understandable language.
Includes Prompt Guard for prompt safety.

Installation
------------
Install the required library:
bash
pip install langchain_groq

API Setup
---------
Create a Groq API key.
Add the API key to Google Colab Secrets.
Set the secret name as groq-demo.
Run the notebook cells.

Example
-------
Question: Which is better, a business or a job?

Response: FUTUREX explores different possibilities, such as financial independence, job stability, business growth, and financial risks.
